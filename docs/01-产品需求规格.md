# 01 · 产品需求规格说明书 (PRD)

> 产品名：**AcrylicDesk**（暂定，可改）
> 定位：常驻屏幕边缘的亚克力桌面管理面板

---

## 1. 产品定位

### 1.1 一句话描述

把 Windows 桌面上的图标、快捷方式、常用文件收纳进一块**贴靠在屏幕边缘、平时完全隐形、
鼠标碰边即滑出**的亚克力透明面板中，让桌面保持干净，同时保证常用程序触手可及。

### 1.2 与参考项目的差异

| 特性 | DawnLauncher | DeskBox | **AcrylicDesk** |
|---|---|---|---|
| 形态 | 独立启动器窗口 | 桌面 Widget 平铺 | **贴边隐藏面板** |
| 唤出方式 | 点击图标/热键 | 常驻可见 | **鼠标碰边自动唤出** |
| 位置 | 固定窗口 | 桌面任意位置 | **上/下/左/右四边可挂** |
| 材质 | 自定义主题 | Mica / Acrylic | **Acrylic 全透明（重点）** |
| 桌面图标管理 | 分类收纳 | 文件夹映射 | **收纳 + 分组 + 拖拽排序** |

**核心差异化**：DeskBox 是"桌面上的贴纸"，本项目是"屏幕边缘的抽屉"。

---

## 2. 用户场景

### 场景 A：保持桌面整洁
> 用户桌面堆了 60 多个图标，影响看壁纸。
> 把常用程序拖进 AcrylicDesk 面板，桌面清空，需要时鼠标往右边缘一推，面板滑出。

### 场景 B：全屏工作时不被打扰
> 用户在全屏写代码/打游戏，面板完全隐身，不遮挡任何内容。
> 只有当鼠标主动撞到屏幕边缘时才唤出。

### 场景 C：多任务快速切换
> 面板分"开发工具"、"设计"、"游戏"三组，滚轮或点击切换，比找桌面图标快。

### 场景 D：个性化外观
> 用户把自己喜欢的壁纸设为面板背景，配合亚克力模糊，与系统壁纸融为一体。

## 4. 交互规格

### 4.1 面板唤出时序（以右侧挂载为例）

```
屏幕右边缘
    │
    │  ← 屏幕外侧（面板隐藏于此）
    │
    ├──── 屏幕可视区边界
    │
    │  ← 触发区（默认 3px）
    │
    │  ← 面板滑出后的位置
```

**唤出流程**：
1. 鼠标 X 坐标 ≥ `屏幕宽度 - 触发区宽度` → 触发
2. 面板从 `x = 屏幕宽度` 动画移动到 `x = 屏幕宽度 - 面板宽度 - 边缘偏移`
3. 动画期间材质降级为 `Blur`，结束后恢复 `Acrylic`
4. 面板进入交互态

**收起流程**：
1. 鼠标离开面板矩形区域 → 启动收起延时计时器（默认 400ms）
2. 延时内鼠标返回面板 → 取消收起
3. 延时结束 → 面板动画滑出屏幕
4. 动画结束后，面板设置为鼠标穿透状态

### 4.2 鼠标穿透策略

| 面板状态 | 鼠标事件 | 说明 |
|---|---|---|
| 完全收起（屏幕外） | `ignore_cursor_events = true` | 不影响任何桌面操作 |
| 滑出动画中 | `ignore_cursor_events = false` | 立即接管鼠标 |
| 展开显示中 | `ignore_cursor_events = false` | 正常交互 |
| 滑入动画中 | `ignore_cursor_events = false` | 保持到动画结束 |

> **设计决策**：不在展开状态下做"局部穿透"。因为面板本身是矩形，局部穿透会导致
> 面板边缘的点击丢失。用户要求"面板上没有窗口时点击穿透到桌面"，
> 通过**面板整体收起时的完全穿透**来满足 —— 收起了就等于不存在。

### 4.3 与 Windows 任务栏的关系

- 若挂载边与任务栏同侧，默认自动让开任务栏（使用 `工作区` 而非 `全屏` 坐标）
- 提供"覆盖任务栏"开关，供高级用户使用
- 面板默认不置顶于全屏应用之上（避免游戏中弹出），提供"全屏时禁用"选项

## 5. 非功能需求

| 编号 | 类别 | 要求 |
|---|---|---|
| NFR-1 | 性能 | 常驻内存 ≤ 120 MB；空闲 CPU ≤ 0.5% |
| NFR-2 | 启动 | 冷启动到面板可用 ≤ 1.5 秒 |
| NFR-3 | 响应 | 碰边到面板完全展开 ≤ 300 ms |
| NFR-4 | 体积 | 绿色版单文件 ≤ 20 MB |
| NFR-5 | 安全 | 不上传任何用户数据；不联网（除可选的更新检查） |
| NFR-6 | 兼容 | Windows 10 2004+ / Windows 11；x64 |
| NFR-7 | 稳定 | 连续运行 7 天无内存泄漏 |
| NFR-8 | 误报 | 主流国产杀软扫描无拦截（绿色版） |

## 6. 明确不做（Out of Scope）

| 项 | 原因 |
|---|---|
| 替代 Explorer 桌面 | 风险高，容易与系统冲突 |
| 云同步 / 账号系统 | 增加复杂度与隐私风险，非核心诉求 |
| 跨平台（macOS/Linux） | 用户明确只要 Windows |
| 内嵌文件管理器 | 超出"桌面管理"范围 |
| 天气/音乐等 Widget | 参考 DeskBox，但非本项目核心；留作未来扩展 |
| 文件加密 | 非诉求，且合规成本高 |
