# 08 · 分发与防误报指南

> 本项目的核心非功能需求之一是"不被杀毒软件拦截"。
> 本文档给出完整的分发策略与误报处理流程。

---

## 1. 策略总览

```
第一层：绿色版优先 —— 不打包安装器，解压即用
第二层：单文件原生 exe —— 不释放子进程、不带运行时
第三层：不碰敏感行为 —— 无全局钩子、无注册表写入（自启除外）
第四层：主动自查 —— 提交多引擎扫描验证
第五层：误报申诉 —— 万一被拦，有标准处理流程
第六层（可选）：代码签名 —— 终极方案
```

---

## 2. 第一层：绿色版优先

### 2.1 为什么

杀软的**安装监控**是最敏感的一环。安装器通常需要：
- 释放大量文件到 `Program Files` / `%AppData%`
- 写注册表
- 创建卸载项
- 可能请求提权

这些行为每一项都会大幅提高启发式评分。

**绿色版跳过了整个安装环节**，解压后只是一个文件夹，风险评分显著降低。

### 2.2 产出结构

```
AcrylicDesk_v1.0.0_portable/
├── AcrylicDesk.exe          ← 主程序（单文件）
├── data/                    ← 用户数据（首次运行自动生成）
├── README.txt               ← 使用说明
├── LICENSE
└── SHA256.txt               ← 校验值
```

**用户操作**：解压到任意目录 → 双击 `AcrylicDesk.exe` → 完事。

### 2.3 构建命令

```powershell
# 不生成安装器，只要 exe
npm run tauri build -- --no-bundle
```

产物位于 `src-tauri/target/release/AcrylicDesk.exe`。

---

## 3. 第二层：单文件原生 exe

Tauri 的天然优势，需确保配置正确：

| 配置项 | 值 | 说明 |
|---|---|---|
| `bundle.targets` | `["nsis"]` 或 `[]` | 绿色版设为空 |
| WebView2 安装模式 | `embedBootstrapper` 或 `skip` | **不要** `downloadBootstrapper`（联网下载会被拦） |
| 是否 AOT | 默认 | Rust 本身就是原生编译 |

### 3.1 ⚠️ 不要在运行时生成可执行文件

以下行为会显著提高误报率，**本项目禁止**：

- ❌ 运行时编译/生成 exe
- ❌ 释放嵌入式资源为可执行文件
- ❌ 动态加载 DLL 到其他进程
- ❌ 反射注入 / 代码注入

（这也是本项目**不用全局钩子**的原因之一，见文档 03 §3.1）

---

## 4. 第三层：敏感行为规避

本项目对常见敏感行为的处理：

| 行为 | 杀软关注度 | 本项目做法 |
|---|---|---|
| 全局键盘/鼠标钩子 | 🔴 极高 | ✅ **不使用**，改轮询 |
| 写 `Run` 注册表自启 | 🟡 中 | ⚠️ 仅自启时写，且用启动文件夹替代优先 |
| 读取浏览器数据 | 🔴 极高 | ✅ 不涉及 |
| 扫描全盘 | 🟡 中 | ✅ 仅扫描桌面/开始菜单 |
| 联网 | 🟡 中 | ✅ 默认不联网 |
| 提权 (UAC) | 🟡 中 | ⚠️ 仅用户主动选择"以管理员运行"时 |
| 修改系统设置 | 🔴 高 | ✅ 不涉及 |
| 进程注入 | 🔴 极高 | ✅ 不涉及 |
| 创建计划任务 | 🟡 中 | ✅ 不使用，用启动文件夹 |

### 4.1 自启实现优选

**优先级 1（推荐）**：启动文件夹快捷方式
```
%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\AcrylicDesk.lnk
```

**优先级 2**：注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`

> 使用 `HKCU`（当前用户）而非 `HKLM`（全局），无需提权，风险更低。

## 5. 第四层：主动自查

### 5.1 多引擎扫描

发布前用以下服务自查：

| 服务 | 地址 | 说明 |
|---|---|---|
| VirusTotal | virustotal.com | 70+ 引擎，必做 |
| 腾讯哈勃 | habo.qq.com | 国内行为分析 |
| 微步在线 | threatbook.cn | 国内威胁情报 |

**验收标准**：VirusTotal 检出率 ≤ 2/70（未签名程序有小概率误报属正常）。

### 5.2 本地实测

在**干净的 Windows 环境**（推荐虚拟机）测试：

- [ ] Windows Defender 实时防护开启下能正常运行
- [ ] 360 安全卫士（开启所有防护）能正常运行
- [ ] 火绒安全能正常运行
- [ ] 腾讯电脑管家能正常运行
- [ ] SmartScreen 提示情况（未签名会有提示，属正常）

### 5.3 ⚠️ 注意本机环境

**本机启用了 Smart App Control**（见文档 07 §2）。
这意味着**在本机测试时，未签名的 exe 可能直接被拦**——这是本机策略所致，
**不代表程序有问题**。

测试误报情况请使用**关闭 SAC 的干净虚拟机**，否则会得到误导性结论。

## 6. 第五层：误报申诉

### 6.1 申诉渠道

| 厂商 | 渠道 | 备注 |
|---|---|---|
| 360 | `open.360.cn` 误报申诉 | 响应较快 |
| 火绒 | `bbs.huorong.cn` 或邮件 | 响应快，人工复核 |
| 腾讯 | `guanjia.qq.com` 申诉 | — |
| 微软 | `microsoft.com/wdsi/filesubmission` | 提交后 24–72h 处理 |

### 6.2 申诉材料模板

```
标题：误报申诉 - AcrylicDesk 桌面管理软件

软件名称：AcrylicDesk
版本：1.0.0
文件大小：约 12 MB
SHA256：<填写>
下载地址：<填写>

软件功能说明：
AcrylicDesk 是一款 Windows 桌面图标管理工具，用于将桌面快捷方式
收纳到屏幕边缘的可唤出面板中。软件为开源软件，源码地址：<填写>。

软件行为说明：
1. 不联网（除可选的版本检查外无任何网络请求）
2. 不安装任何驱动或服务
3. 不使用全局钩子（鼠标位置检测采用 60Hz 轮询 GetCursorPos）
4. 仅在用户主动开启时写入 HKCU 自启项
5. 所有数据存储在软件所在目录的 data 子目录中

希望协助复核，谢谢。
```

### 6.3 申诉前的准备

- ✅ 准备好 SHA256 校验值
- ✅ 准备好源码地址（开源大幅提升通过率）
- ✅ 准备好详细的行为说明
- ✅ 附上 VirusTotal 扫描链接（若检出率低）

## 7. 第六层：代码签名（可选）

### 7.1 证书类型对比

| 类型 | 价格 | 效果 | 推荐度 |
|---|---|---|---|
| 无签名 | 0 | SmartScreen 警告，部分杀软误报 | 自用可接受 |
| OV 证书 | ¥1000–3000/年 | 消除警告，需积累信誉 | ⭐⭐ |
| EV 证书 | ¥3000–8000/年 | **立即**消除 SmartScreen 警告 | ⭐⭐⭐ |

### 7.2 何时需要

| 场景 | 是否需要签名 |
|---|---|
| 自己用 | ❌ 不需要 |
| 小范围分享给朋友 | ⚠️ 可选，附校验值即可 |
| 公开发布/商业分发 | ✅ 强烈建议 |
| 想彻底消除杀软疑虑 | ✅ 建议 EV |

### 7.3 配置（Tauri）

```json
{
  "bundle": {
    "windows": {
      "certificateThumbprint": "<证书指纹>",
      "digestAlgorithm": "sha256",
      "timestampUrl": "http://timestamp.digicert.com"
    }
  }
}
```

或用 `signCommand` 配合云签名服务。

## 9. 用户侧说明

在 `README.txt` 中向用户说明：

```
【如果杀毒软件提示风险】

本软件为开源软件，未购买商业代码签名证书，因此部分杀毒软件可能
产生误报。这不是软件存在问题。

您可以通过以下方式验证：
1. 核对 SHA256 校验值（见 SHA256.txt）
2. 查看开源源码：<地址>
3. 查阅 VirusTotal 扫描报告：<链接>

如仍然被拦截，可：
- 将软件目录加入杀软白名单
- 或通过上述渠道提交误报申诉

【卸载方法】

1. 关闭 AcrylicDesk
2. 删除整个文件夹即可
3. 若开启了开机自启，请在设置中先关闭；
   或手动删除：
   %APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\AcrylicDesk.lnk

所有用户数据都保存在软件目录的 data 文件夹内，
删除文件夹即彻底清除，不残留任何系统痕迹。
```
