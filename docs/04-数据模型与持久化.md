## 1. 存储位置

### 1.1 便携优先策略

```
优先级 1：<exe所在目录>\data\        ← 绿色版，可写时使用
优先级 2：%APPDATA%\AcrylicDesk\     ← 回退（exe 在 Program Files 等只读位置时）
```

启动时探测，结果缓存在内存中。

### 1.2 目录结构

```
data/
├── config.json          主配置
├── icons/               图标缓存（PNG，以内容哈希命名）

├── backgrounds/         用户背景图副本（可选，默认只存路径）

├── backups/             配置自动备份（保留最近 5 份）
│   ├── config-20261010-153000.json
│   └── ...
└── logs/
    └── app.log
```

## 3. 数据结构定义 (Rust)

```rust
// config/schema.rs

use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Config {
    pub version: u32,
    pub panel: PanelConfig,
    pub edge: EdgeConfig,
    pub appearance: AppearanceConfig,
    pub groups: Vec<Group>,
    pub active_group_id: Option<String>,
    pub system: SystemConfig,
}

#[derive(Debug, Clone, Copy, Serialize, Deserialize, PartialEq)]
#[serde(rename_all = "lowercase")]
pub enum Edge {
    Top,
    Bottom,
    Left,
    Right,
}

impl Edge {
    /// 判断该边是水平挂载（上/下）还是垂直挂载（左/右）
    pub fn is_horizontal(&self) -> bool {
        matches!(self, Edge::Top | Edge::Bottom)
    }

    /// 窗口尺寸中，哪个是"长度"，哪个是"厚度"
    pub fn to_window_size(&self, length: u32, thickness: u32) -> (u32, u32) {
        if self.is_horizontal() {
            (length, thickness)   // 上/下：宽=长度，高=厚度
        } else {
            (thickness, length)   // 左/右：宽=厚度，高=长度
        }
    }
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct PanelConfig {
    pub edge: Edge,
    pub monitor_index: usize,
    pub length: u32,
    pub thickness: u32,
    pub offset: i32,
    pub corner_radius: f64,
    pub always_on_top: bool,
    pub cover_taskbar: bool,
    pub auto_size: bool,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct EdgeConfig {
    pub trigger_width: i32,
    pub hide_delay: u64,
    pub animation_duration: u64,
    pub enable_hover: bool,
    pub disable_on_fullscreen: bool,
    pub summon_hotkey: String,
    pub always_visible: bool,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct AppearanceConfig {
    pub effect: EffectKind,
    pub opacity: f64,
    pub theme: ThemeKind,
    pub accent_color: String,
    pub background: BackgroundConfig,
    pub icons: IconStyleConfig,
}

#[derive(Debug, Clone, Copy, Serialize, Deserialize, PartialEq)]
#[serde(rename_all = "lowercase")]
pub enum EffectKind { Acrylic, Mica, Blur, Solid }

#[derive(Debug, Clone, Copy, Serialize, Deserialize, PartialEq)]
#[serde(rename_all = "lowercase")]
pub enum ThemeKind { System, Light, Dark }

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct BackgroundConfig {
    pub r#type: BgType,
    pub image_path: Option<String>,
    pub fit: BgFit,
    pub dim: f64,
    pub color: String,
}

#[derive(Debug, Clone, Copy, Serialize, Deserialize, PartialEq)]
#[serde(rename_all = "lowercase")]
pub enum BgType { None, Image, Color }

#[derive(Debug, Clone, Copy, Serialize, Deserialize, PartialEq)]
#[serde(rename_all = "lowercase")]
pub enum BgFit { Cover, Contain, Fill, Tile, Center }

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct IconStyleConfig {
    pub size: u32,
    pub show_label: bool,
    pub label_lines: u8,
    pub gap: u32,
    pub grid_columns: u32,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Group {
    pub id: String,
    pub name: String,
    pub icon: String,
    pub order: i32,
    pub items: Vec<IconItem>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct IconItem {
    pub id: String,
    pub r#type: ItemType,
    pub name: String,
    pub target: String,
    pub args: String,
    pub work_dir: String,
    pub icon_path: Option<String>,
    pub source_path: Option<String>,
    pub run_as_admin: bool,
    pub order: i32,
    pub added_at: String,
}

#[derive(Debug, Clone, Copy, Serialize, Deserialize, PartialEq)]
#[serde(rename_all = "lowercase")]
pub enum ItemType { App, Folder, File, Url }

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct SystemConfig {
    pub auto_start: bool,
    pub start_minimized: bool,
    pub language: String,
    pub check_update: bool,
}
```

## 4. 持久化策略

### 4.1 原子写入

防止写入过程中崩溃导致配置损坏：

```rust
pub fn save_atomic(path: &Path, config: &Config) -> Result<()> {
    let tmp = path.with_extension("json.tmp");
    let json = serde_json::to_string_pretty(config)?;

    // 1. 先写临时文件
    std::fs::write(&tmp, json)?;

    // 2. 原子替换
    #[cfg(windows)]
    std::fs::rename(&tmp, path)?;   // Windows 上 rename 会覆盖已存在文件

    Ok(())
}
```

> **注意**：Windows 的 `std::fs::rename` 在目标存在时会**覆盖成功**（不同于 Unix 语义），
> 无需先删除。若需更严格，可用 `MoveFileExW` + `MOVEFILE_REPLACE_EXISTING`。

### 4.2 防抖写入

避免频繁拖动排序时反复写盘：

```rust
pub struct ConfigStore {
    inner: Arc<Mutex<Config>>,
    dirty: Arc<AtomicBool>,
    path: PathBuf,
}

impl ConfigStore {
    /// 标记为脏，500ms 后统一落盘
    pub fn mark_dirty(&self) {
        self.dirty.store(true, Ordering::SeqCst);
        // 由后台线程每 500ms 检查一次
    }
}
```

### 4.3 自动备份

每次成功保存前，若距上次备份超过 10 分钟，则复制一份到 `backups/`，
保留最近 5 份。

## 5. 配置迁移

```rust
pub fn migrate(cfg: &mut serde_json::Value) -> Result<()> {
    let ver = cfg.get("version").and_then(|v| v.as_u64()).unwrap_or(0);

    if ver < 1 {
        // v0 → v1: 初始版本，无需迁移
    }

    // 未来版本在此追加迁移逻辑
    // if ver < 2 { ... }

    cfg["version"] = serde_json::json!(CURRENT_VERSION);
    Ok(())
}
```

**原则**：
- 迁移函数必须**幂等**
- 迁移前自动备份
- 迁移失败时保留原文件并报错，不静默重置（避免用户配置丢失）

## 7. 图标缓存策略

| 项 | 策略 |
|---|---|
| 命名 | `<原始路径的FNV-1a哈希16位>.png` |
| 尺寸 | 提取 32×32 系统大图标，前端按需缩放 |
| 失效 | 启动时校验 `sourcePath` 是否存在，不存在则标记为失效（灰色显示） |
| 清理 | 每周清理一次未被任何 item 引用的图标文件 |
| 格式 | PNG（保留 alpha 通道，exe 图标常有透明区域） |

> ⚠️ **不要**直接在前端通过 `<img src="file:///...">` 引用本地 exe 图标 ——
> WebView2 不允许跨协议加载本地文件。必须经 Rust 提取后以 base64 或
> Tauri asset 协议提供。

### 7.1 提取实现（已验证）

使用 Win32 `SHGetFileInfoW` 链路：

```
SHGetFileInfoW(path, 0, &info, size, SHGFI_ICON | SHGFI_LARGEICON)
    │
    ├─ 返回 HICON
    ▼
GetIconInfo(hicon, &iconinfo)   → 取出 hbmColor / hbmMask
    │
    ▼
GetObjectW(hbmColor, BITMAP)    → 取宽高
    │
    ▼
GetDIBits(..., 32bpp, BI_RGB)   → 取 BGRA 像素
    │
    ▼
BGRA → RGBA（交换 R/B 通道）
    │
    ├─ 若 alpha 全为 0 → 视为无 alpha，全部置 255
    ▼
image::ImageBuffer → PNG 编码
    │
    ▼
DestroyIcon(hicon)              → 释放句柄
```

### 7.2 ⚠️ 陷阱：windows crate 的 feature 门控

`windows` crate 的所有 API 都受 **Cargo feature 门控**。
缺少 feature 时，错误信息会误导性地说"路径不存在"，
例如：

```
error[E0433]: cannot find `Storage` in `Win32`
```

**实际原因**：`Cargo.toml` 里缺少 `Win32_Storage_FileSystem` feature，
而不是路径写错。

**本项目需要的 features**：

```toml
windows = { version = "0.58", features = [
    "Win32_Foundation",
    "Win32_UI_WindowsAndMessaging",
    "Win32_UI_Shell",
    "Win32_UI_Shell_Common",
    "Win32_Storage_FileSystem",   # SHGetFileInfoW 的参数类型在此
    "Win32_Graphics_Gdi",         # GetDIBits / BITMAP
    "Win32_Graphics_Dwm",
    "Win32_System_Com",           # IShellLinkW
    "Win32_System_LibraryLoader",
    "Win32_System_SystemInformation",
    "Win32_UI_HiDpi",
] }
```

> **排查方法**：先到 `~/.cargo/registry/src/*/windows-0.58.0/src/Windows/Win32/`
> 下搜索函数名，确认它属于哪个模块，再回 Cargo.toml 补对应 feature。

### 7.3 ⚠️ 陷阱：GetPath 的签名差异

`windows` 0.58 中 `IShellLinkW::GetPath` 的签名是：

```rust
pub unsafe fn GetPath(
    &self,
    pszfile: &mut [u16],                          // 可变切片，非裸指针
    pfd: *mut WIN32_FIND_DATAW,                   // 可为 null
    fflags: u32,                                  // SLGP_RAWPATH.0 as u32
) -> windows_core::Result<()>
```

与 C 原型的 `LPWSTR pszFile` 不同，Rust 侧改用切片，
**不需要也不应该传缓冲区长度的参数**。
