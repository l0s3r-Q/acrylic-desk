## 实测性能数据

### Debug 版 vs Release 版

| 指标 | Debug | **Release** | 目标 | 结论 |
|---|---|---|---|---|
| exe 体积 | 15.35 MB | **3.73 MB** | ≤ 20 MB | ✅ 远超预期 |
| 内存占用 | 34.7 MB | **29.9 MB** | ≤ 120 MB | ✅ 优秀 |
| 线程数 | 33 | 33 | — | ✅ |
| 冷启动 | < 2 秒 | < 2 秒 | ≤ 1.5 秒 | ✅ 接近 |

### 与参考项目对比

| 项目 | 技术栈 | 体积（估） | 内存（估） |
|---|---|---|---|
| DawnLauncher | Electron | ~150 MB | 300–500 MB |
| DeskBox | C# WinUI 3 + AOT | ~40–80 MB | 80–150 MB |
| **AcrylicDesk** | **Tauri 2** | **3.73 MB** | **29.9 MB** |

> **注**：体积优势来自 Tauri 复用系统 WebView2，
> 不打包 Chromium 运行时。这也正是杀软误报率低的原因。

### Release 构建配置

```toml
[profile.release]
codegen-units = 1    # 最大化优化
lto = true           # 链接时优化
opt-level = "s"      # 优化体积
panic = "abort"      # 去掉 panic 展开表
strip = true         # 剥离符号
```

## 开发原则

1. **每个阶段结束必须能运行验证**，不堆积未测试代码
2. **后端先行**：Rust 侧能力完备后再做前端，避免前端做无米之炊
3. **契约优先**：严格按 `05-API契约.md` 实现，前后端并行不冲突
4. **安全红线**：不使用全局钩子、不注入进程、不写注册表（除自启外）
5. **踩坑即记录**：新发现的坑立刻写入对应文档
